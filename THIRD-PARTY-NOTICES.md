# Third-party software

## FFmpeg

FloatCam portable builds bundle FFmpeg.

The currently tested build uses:

FFmpeg 9.0.1 full build from gyan.dev

The bundled FFmpeg build was compiled with GPL and GPLv3 features enabled.

FFmpeg is a separate third-party project and is distributed under its applicable open-source licences.

Project:
https://ffmpeg.org/

Windows build provider:
https://www.gyan.dev/ffmpeg/builds/

FFmpeg licence information:
https://ffmpeg.org/legal.html

When redistributing FloatCam with the bundled FFmpeg executable, the applicable FFmpeg licence requirements must also be observed.
